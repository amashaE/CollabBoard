# Calendar / Deadlines

This component provides the Calendar and Deadlines feature for CollabBoard.

## Features

- Monthly calendar view
- Previous and next month navigation
- Display tasks on their deadline dates
- Priority indicators
- Upcoming deadlines list
- Responsive design

## Files

- `Calendar.jsx` - Calendar component and functionality
- `Calendar.css` - Styling for the calendar and deadlines

## Integration

Import the component:

```jsx
import Calendar from "./components/Calendar/Calendar";
